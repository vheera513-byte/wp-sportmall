# اسپرت‌مال — قالب وردپرس و ووکامرس

قالب فروشگاهی راست‌به‌چپ اسپرت‌مال، ساخته‌شده بر پایهٔ طراحی صفحه اصلی همین مخزن. قالب فقط به صفحه اصلی محدود نیست و همهٔ صفحات استاندارد فروشگاه، ژورنال و محتوای ادیتوریال را پوشش می‌دهد.

## نصب

1. پوشهٔ `sportmall` را در `wp-content/themes/` قرار بده (یا از `zigzag`/آپلود قالب نصب کن).
2. وردپرس و ووکامرس را فعال کن. برای استفاده از فروشگاه، ووکامرس الزامی است؛ بقیهٔ بخش‌ها بدون آن هم کار می‌کنند.
3. در پیشخوان به **نمایش > محتوای نمونه** برو و دکمهٔ «ساخت / تکمیل محتوای نمونه» را بزن.
4. در **تنظیمات > پیوندهای یکتا** روی «نام نوشته» ذخیره کن.
5. در **نمایش > فهرست‌ها** می‌توانی منوی اصلی را به جای منوی خودکار دسته‌بندی‌ها انتخاب کنی. منوهای فوتر به‌صورت خودکار ساخته می‌شوند.

> اگر ووکامرس از قبل نصب است، صفحه‌های فروشگاه، سبد خرید، تسویه‌حساب و حساب کاربری در صورت نبود ساخته و به ووکامرس متصل می‌شوند. واحد پول پیش‌فرض «تومان» تنظیم می‌شود.

## محتوای نمونه

ابزار نمونه‌ساز این موارد را می‌سازد:

- دسته‌بندی‌های محصولات: زنانه، مردانه، کفش، پوشاک، اکسسوری، دویدن، تمرین و زیرشاخه‌ها.
- ویژگی‌های سراسری `brand`، `size` و `color` با برندهای نایک، آدیداس، پوما، آسیکس، نیوبالانس، ریبوک، آندرآرمور و اسکچرز.
- ۱۰ محصول نمونهٔ فارسی با تصویر، قیمت تومانی، تخفیف، سایز، رنگ و دسته‌بندی؛ بعضی محصولات متغیر (variable) با واریاسیون سایز هستند.
- ۳ ست ورزشی، ۵ استوری مشتری و ۴ نوشتهٔ ژورنال با دسته‌بندی.
- برگه‌های خانه، ژورنال، فروشگاه، سبد خرید، تسویه‌حساب، حساب کاربری، علاقه‌مندی‌ها، تماس با ما، درباره، ارسال، بازگشت، راهنمای سایز، سوالات متداول و حریم خصوصی.
- منوهای فوتر خرید، راهنما و درباره.

اجرای دوبارهٔ ابزار، محتوای تکراری نمی‌سازد؛ آیتم‌های موجود با slug یکسان شناسایی و تکمیل می‌شوند.

## ساختار قالب

```
sportmall/

│   ├── css/base.css          # سیستم طراحی و استایل صفحه اصلی
│   ├── css/pages.css         # صفحات داخلی، فروشگاه، ژورنال، تماس، علاقه‌مندی
│   ├── css/woocommerce.css   # محصول، سبد، تسویه، حساب کاربری و ویجت‌ها
│   ├── js/theme.js           # اسلایدر، مگامنو، دیالوگ‌ها، جستجوی AJAX، علاقه‌مندی
│   ├── fonts/vazirmatn.woff2
│   └── images/
├── inc/
│   ├── setup.php             # قابلیت‌ها، منوها، سایدبارها، اندازه تصاویر
│   ├── icons.php             # اسپرایت SVG
│   ├── template-tags.php     # تابع‌های نمایشی و کوئری‌های محتوا
│   ├── nav.php               # منوی اصلی و مگامنوی خودکار
│   ├── customizer.php        # تنظیمات صفحه اصلی، اسلایدها، فوتر
│   ├── stories.php           # نوع محتوای استوری و ست + متاباکس‌ها
│   ├── newsletter.php        # فرم و مدیریت خبرنامه
│   ├── contact.php           # فرم تماس
│   ├── search.php            # جستجوی AJAX و علاقه‌مندی‌ها
│   ├── woocommerce.php       # یکپارچگی ووکامرس، فیلترها، قیمت تومان
│   └── demo-content.php      # نمونه‌ساز یک‌کلیکی
├── template-parts/           # کارت‌ها، هدر، بخش‌های صفحه اصلی
├── woocommerce/              # آرشیو محصول، کارت محصول، صفحه محصول
├── page-templates/           # علاقه‌مندی، تماس، تمام‌عرض
├── front-page.php
├── page.php
├── single.php
├── archive.php
├── search.php
├── 404.php
├── comments.php
└── functions.php
```

## صفحات و قالب‌ها

| مسیر | قالب | توضیح |
| --- | --- | --- |
| صفحه اصلی | `front-page.php` | هیرو، دسته‌بندی سریع، دسته‌ها، تخفیف‌ها، کاتالوگ، ست‌ها، دویدن، پیشنهاد، استوری‌ها، ژورنال، خدمات |
| فروشگاه و آرشیو محصول | `woocommerce/archive-product.php` | فیلتر دسته/قیمت/برند، مرتب‌سازی، تخفیف و موجودی |
| محصول | `woocommerce/single-product.php` | گالری، واریاسیون سایز، تب‌ها، محصولات مرتبط |
| سبد خرید | `page.php` + `[woocommerce_cart]` | استایل کامل جدول، کوپن، جمع سبد و ارسال |
| تسویه‌حساب | `page.php` + `[woocommerce_checkout]` | دو ستونه، فیلدهای فارسی، درگاه و خلاصه سفارش |
| حساب کاربری | `page.php` + `[woocommerce_my_account]` | ورود/ثبت‌نام، سفارش‌ها، آدرس‌ها، جزئیات حساب |
| جستجو | `search.php` | تفکیک محصولات و نوشته‌ها + فرم جستجو |
| ژورنال | `index.php` / `archive.php` / `single.php` | آرشیو و مطلب با سایدبار و مطالب مرتبط |
| استوری مشتریان | `single-sm_story.php` + `archive.php` | نقل‌قول، محصول همراه، استوری‌های دیگر |
| ست‌های ورزشی | `single-sm_outfit.php` + `archive.php` | قیمت مجموع، آیتم‌ها، ست‌های دیگر |
| علاقه‌مندی‌ها | `page-templates/wishlist.php` | ذخیره در مرورگر + رندر AJAX |
| تماس با ما | `page-templates/contact.php` | فرم امن با nonce و honeypot |
| ۴۰۴ | `404.php` | جستجو، دسته‌ها و محصولات پیشنهادی |

## سفارشی‌سازی

همهٔ متن‌ها و اسلایدهای صفحه اصلی از **نمایش > سفارشی‌سازی > تنظیمات اسپرت‌مال** قابل ویرایش‌اند. لوگو از **هویت سایت** خوانده می‌شود. اگر منوی اصلی انتخاب نشود، منو از دسته‌بندی‌های ووکامرس و مگامنوی خودکار ساخته می‌شود.

## نکته‌های فنی

- وابستگی به jQuery فقط برای رویدادهای افزودن به سبد ووکامرس است؛ بقیهٔ تعامل‌ها وانیلا جاوااسکریپت هستند.
- تصاویر نمونه داخل قالب هستند و هنگام نمونه‌سازی به کتابخانهٔ رسانه منتقل می‌شوند.
- علاقه‌مندی‌ها در `localStorage` با کلید `sportmall-favorites-v1` ذخیره می‌شوند.
- برای تغییر واحد پول، در تنظیمات ووکامرس «تومان ایران (IRT)» را انتخاب کن.
- قالب با PHP 7.4+ و وردپرس 6.4+ سازگار است و از HPOS ووکامرس پشتیبانی می‌کند.
