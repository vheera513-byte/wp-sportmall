# اسپرت‌مال

## قالب وردپرس + ووکامرس

نسخهٔ کامل قالب در پوشهٔ [`sportmall/`](sportmall/) قرار دارد. این قالب بر پایهٔ همان طراحی صفحه اصلی ساخته شده و شامل صفحه اصلی، فروشگاه و آرشیو محصولات، صفحه محصول، سبد خرید، تسویه‌حساب، حساب کاربری، جستجو، ژورنال، استوری مشتریان، ست‌های ورزشی، علاقه‌مندی‌ها، تماس با ما و ۴۰۴ است. راهنمای نصب و نمونه‌سازی در [`sportmall/README.md`](sportmall/README.md) آمده است.

**دانلود آمادهٔ نصب:** فایل [`sportmall-theme.zip`](sportmall-theme.zip) همین قالب را به‌صورت آرشیو قابل آپلود در وردپرس دارد.

> صفحه اصلی HTML (`index.html`) به‌عنوان مرجع بصری و پیش‌نمایش طراحی باقی مانده است. نسخهٔ وردپرسی، منبع اصلی سایت است.

## پیش‌نمایش HTML

هوم‌پیج فارسی و راست‌به‌چپ، بدون وابستگی به نصب پکیج یا فرایند ساخت.

برای مشاهده، `index.html` را باز کنید. پیش‌نمایش این جلسه در `http://127.0.0.1:8766` اجرا شده است. همهٔ عکس‌ها، لوگوها و فونت به‌صورت محلی در `assets` هستند.

- فایل اصلی: `index.html`
- استایل تکمیلی: `assets/home.css`
- کاتالوگ و تعاملات: `assets/home.js`
- بخش‌های تازهٔ دسکتاپ و تعاملات آن‌ها: `assets/editorial.css` و `assets/editorial.js`
- مقیاس مشترک تایپوگرافی، فاصله‌گذاری و کنترل‌های دسکتاپ: `assets/scale.css`؛ توکن‌های `rem` و `clamp()` برای تغییر تدریجی اندازه با عرض صفحه.
- نسخهٔ دست‌نخوردهٔ اولیه: `index.original.html`

جستجو، دسته‌بندی، علاقه‌مندی‌ها، انتخاب سایز، سبد خرید، راهنماها و کپی کد پیشنهاد در همین صفحه کار می‌کنند. بخش‌های جدید شامل دسته‌بندی مستقیم زیر هیرو، تخفیف‌های روز، سه ست کامل با امکان انتخاب سایز هر آیتم و افزودن یک‌جای ست به سبد، و چهار استوری قابل بازشدن هستند. سبد و علاقه‌مندی‌ها در مرورگر ذخیره می‌شوند. این نمونهٔ رابط کاربری است؛ پرداخت، حساب کاربری و عضویت ایمیلی واقعی متصل نیستند. قیمت‌ها، پیشنهادها، نام‌ها و روایت‌های مشتریان نمونه‌اند.

ارتفاع هیرو کمتر شده و صفحه‌بندی کپسولی اولیه حفظ شده است. کنترل پخش و نوشته‌های اضافهٔ پایین اسلایدر حذف شده‌اند. فقط فلش‌ها پرداخت بصری تازه دارند.
